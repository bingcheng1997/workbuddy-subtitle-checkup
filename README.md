# 字幕体检中心

WorkBuddy 技能：给已有字幕做一次全面体检——结构性问题自动修复，平台违禁词分级扫描，产出可作为内部初筛记录的体检报告。

市面工具多数只修格式，本技能同时管「能不能过审」：时间轴、行长、阅读速度自动修复归零；违禁词按平台词库分级标注，支持谐音变体归一化，全部留痕。

## 功能

- **结构性问题自动修复**：时间轴重叠 / 倒置 / 乱序、过短过长、单行超长、阅读速度超标、序号错乱、空条目；修复后按阅读速度统一重排，复检归零
- **违禁词分级扫描**：广告法绝对化、医疗功效、金融承诺、站外引流、施压营销、诱导互动六类；支持繁简转换、全半角统一、常见谐音 / 拆字变体归一化
- **词库版本化**：报告标注词库版本、更新日期、条目数与依据规则，团队口径可对齐、可追溯
- **审计级报告**：检查时间、文件指纹、覆盖率、起止时间码定位、总体结论（通过 / 整改后复检 / 不通过）、处置记录栏；文件名带时间戳，历史报告不覆盖
- **单文件或整文件夹批量**：逐文件独立报告 + 汇总表（条数 / 高危数 / 中危数 / 结论）
- **格式与编码兼容**：SRT / VTT / ASS（自动剥离样式标签后体检，按原格式回写）；UTF-8 / GBK 自动探测

## 安装

1. 下载 [Releases](../../releases) 中的技能包 zip
2. 打开 WorkBuddy → 技能栏 → 导入本地技能包 → 选择 zip
3. 也可以把仓库中的 `SKILL.md` 放入 `~/.workbuddy/skills/subtitle-checkup/`

## 使用

对 WorkBuddy 说：

```
扫一下这条字幕能不能发抖音
把这个文件夹里的字幕全部体检一遍
修复这条字幕的时间轴，报告发我
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| 字幕文件 / 文件夹 | 必填 | srt / vtt / ass，支持批量 |
| 目标平台 | 询问 | 抖音 / B站 / 小红书 / 视频号 / 公众号，决定词库 |
| 自定义违禁词表 | 无 | 每行一词，团队被罚过的词沉淀进来 |
| 白名单 | 无 | 命中但应豁免的词，豁免记录写入报告 |

## 输出物

保存到 `字幕体检/`：

```
20261030_120000_course01_体检报告.md   审计头 + 问题清单 + 处置栏
course01_修复版.srt                    结构性问题已全部修复
（批量模式）汇总表                      各文件高危 / 中危数与结论
```

## 使用须知

- 检查范围是**字幕文本**：画面二维码、音频口误、BGM 版权、标题封面不在覆盖范围，需人工或其他工具配合
- 定位是过审前的高质量初筛：变体映射覆盖常见形式，拼音缩写与新造谐音词不保证检出；「0 问题」也建议人工复核
- 内容性问题只标注、给替换建议，不改写你的文案，决定权在用户
- 修复版时间轴会统一重排，报告内有明确注明

## 测试

仓库内置自动化测试（8 类缺陷检出与修复归零、违禁词定级与留痕、审计要件完整性）：

```bash
cd tests && python3 run_tests.py
```
